# 献立プランナー

自分で作れるメニューを登録しておくと、それ以外の日は時短・材料が手に入りやすい定番レシピを自動で組み合わせて1ヶ月分の献立を作成するアプリです。iPhoneのホーム画面に追加してアプリのように単独で使えます(PCを起動しておく必要はありません。他端末との同期もしません。データは使っている端末の中だけに保存されます)。

## できること

- 自分で作れるメニューの登録・編集・削除
- ボタン一つで1ヶ月分の献立を自動作成(連続で同じメニューにならないよう調整)
- カレンダー画面で献立の確認・個別変更(選び直し/おまかせで変更)
- カレンダーで日付を選ぶと、その日数分の必要な食材を買い物リストとして表示・チェックしながら買い物できる
- 調味料・常備品が切れたらチェックしておくと、買い物リストに自動で追加される

## 技術構成

- Vite + React + TypeScript
- PWA(`vite-plugin-pwa`): オフラインでも動作し、iPhoneのホーム画面にアプリとして追加できます
- データはブラウザの `localStorage` に保存(サーバー不要・端末内で完結)

## ローカルで動かす

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
npm run preview
```

## iPhoneで使う(スマホ1台で完結させる方法)

このリポジトリを GitHub Pages に公開すると、パソコンを起動していなくても iPhone だけでアクセスできるようになります。

1. GitHub のリポジトリ設定 → **Settings > Pages** で、Source を **GitHub Actions** に設定する
2. `main` ブランチに push すると `.github/workflows/deploy.yml` が自動でビルド・公開します(公開URLは Actions の実行結果やSettings > Pagesに表示されます)
3. iPhoneのSafariで公開URLを開く
4. 共有ボタン → **「ホーム画面に追加」** をタップ

ホーム画面に追加すると、通常のアプリのようにアイコンから起動でき、一度開いた後はオフラインでも利用できます。データは追加したその端末にのみ保存され、他の端末とは同期しません。
